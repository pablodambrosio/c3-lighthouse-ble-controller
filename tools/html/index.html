Pickers set chromaticity only. Black maps to white; use brightness or power to darken the LEDs. Exact x,y values are preserved until edited. End color is used in Gradient mode.

03 / Movement

Cycle sweeps hues in Mono or rotates the Gradient. Random shifts each LED independently.

Must be greater than zero for Cycle and Random.
